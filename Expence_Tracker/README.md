# 💰 Expense Tracker

A simple command-line based **Expense Tracker** built using Python.

This application allows users to record, view, update, delete, and search their daily expenses. It also provides total expense and category-wise expense reports.

---

## 📌 Project Description

Expense Tracker is a Python-based application designed to help users maintain a record of their daily expenses.

Users can add expenses with details such as:

* Amount
* Category
* Description
* Date

All expense data is stored permanently in a JSON file, so the data remains available even after closing the program.

---

## ✨ Features

### 1. Add Expense

Users can add a new expense by entering:

* Amount
* Category
* Description

The current date is automatically added.

---

### 2. View All Expenses

Displays all stored expenses in a table containing:

* Expense ID
* Date
* Category
* Amount
* Description

---

### 3. Update Expense

Users can update an existing expense using its Expense ID.

They can change:

* Amount
* Category
* Description

---

### 4. Delete Expense

Users can delete an existing expense by entering its Expense ID.

---

### 5. Search Expenses

Expenses can be searched using:

* Category
* Date
* Amount
